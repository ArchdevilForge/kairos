# 0002 桌面设置切换 daemon 行情源

Status: accepted

Date: 2026-11-18

## 背景

图表、MarketPulse 与异动通知必须一起切换。行情检测器持有交易所特有的滑动窗口、价格和订阅状态。

## 决策

设置持久化覆盖值，daemon 在同一 HTTP 监听地址下依次关闭旧实例并启动一个新 pipeline 和 Desk API 实例。K 线缓存按来源索引并保留旧缓存表，历史数据从有来源标签且沿用同一时间边界的记录导入。

## 后果

切换时有短暂重连和检测器预热。账户、图形标注、风控配置和交易流水保留。切回原市场可复用其已缓存的 K 线。
