# EP06 · 20231202 · 经典行情走盘：USTC、BIGTIME 全周期（附他的犯病实录）

> 补记（2026-11-10）：本集转写 2026-11-09 已完成，但逐集笔记当时漏写、STRATEGY 亦未引用；2026-11-10 盘点产物时发现并补上。本集他自述「这周单子做得比较乱，就不讲单子了」，改讲上周两只经典行情从头到尾该怎么做。

## 行情背景
- 大饼处于箱体内部的向上反弹周期：他的目标区是 42,000 以上——「来到 42,000 就来到我的预期卖出位置了，到哪停我就在哪出」；42k 后再往上的行情会相当难做。
- 以太（9:08）：大级别结构「没有不涨的理由」，若启动 3000 板上钉钉，防守 2050；但介入时点说不清（可能被大饼带突破，也可能大饼横盘时独立起），到点位先关注起来。本轮参照系是 2019 年那波反弹行情（历史同构）。
- 当周龙头 BIGTIME（次新、人气高）；ORDI 盘整时间不够、等收平台；山寨要再走强，需要大饼继续往上攀升一步步带。

## 核心观点
1. **持仓的唯一锚**（6:28）：「我不知道他要怎么走、能到哪，我唯一能知道的是——他如果跌穿我的成本，这波行情就结束了。」不跌穿就拿着，跌穿就拜拜。路径不可知，失效点可知。
2. **龙头识别四件套**（16:50）：不用学怎么判断龙头——主升浪 + 量大 + 人气高 + 幅度大，就是龙头。市场是多头氛围时，手里有盈利的单子多拿多捂；没单子的，要么找短线，要么等。
3. **大饼脸色原则**：上周大饼高位要死不活地震荡，山寨全无独立性（大饼涨他涨、大饼跌他跌），此时山寨自己的走势参考价值下降，突破要参照大饼状态；例外是量能与人气都够的独立龙头（USTC），可以不看大饼脸色。但他强调这只是相对特殊的阶段——大部分时间仍以个股走势为主；实操折中：突破后若总是磨叽、没有量能跟随，就相对谨慎一点。
4. **山寨启动略早于大饼**：大饼到收敛末期，就有人提前去打山寨（LTA 11/29 8 点案）——经典的小分歧介入：跑到箱底低吸、箱底防守、做二波。（EP07 共振律的先行版。）

## 操作与交割（两只票的全周期走盘）
### USTC（独立龙头全周期）
- 底部箱底震荡段没有逻辑可言；**击穿关键压力 20（25:23）= 空间打开**：20 的位置刚好收敛一下、重新突破，突破后量能与之前完全不是一个级别，开始加速——至少看到 25/26。
- 高位加速完必有大分歧：插针下来就知道短期没行情了，不赌多、不赌空、不做震荡，等收敛。
- **二次探底（27:26）出现才重新关注**：踩住、收好、再往上走 = 整体向上突破的预期；坐在区间里防守，止损了没关系，再找一次机会。
- 拿法：拿到五分钟级别二波没上去的位置出，或者加速了再出。用浪型数：一浪启动→调整→三浪→调整→五浪，一轮结束；加速完短期就是震荡。**同一个位置第二次再收好做多，性价比已完全不同**（余位行情）——位置相同，阶段不同，打法不同。
- 结束点形态：五浪 + 假突破 + 小平台往下一走 = 整波行情结束，那个点位可以做空头，但逆势单不长拿。
- 全程复盘结论：一整轮能打的只有 **4 笔交易，每笔试错 3 次、共 12 笔**（32:09），多了全是无效交易；其余时段都是垃圾行情（32:46）——「哪怕幅度大，确定性没有这一段高，就是垃圾行情；这一段幅度小但确定性高，就是好行情。」
- 反面示范（36:38）：直播时 USTC 已是箱底震荡，他自承做了无逻辑单还亏钱——「结构漂亮是美丽的陷阱」，没有逻辑的单少做；要在有逻辑的位置重仓把握。

### BIGTIME（龙头全周期 + 他的犯病实录）
- 定性：箱体结构 + 人气票 + 次新，若往上走幅度会大；正确打法是回踩企稳介入、防守区间明确。
- 他的四个错（自剖）：①企稳接多后，因为觉得大饼不好提前出掉、没格局；②回踩踩稳往上走的关键点睡过去了，没做；③醒来被迫追高——追高时想好了止损要放大，**实际又没放大**，被扫掉 7000U；④再追时自己设的止损没坚持、提前出场。
- **止损有效性（41:25）**：小分歧里把止损放在突破位是无效的，「小分歧只有（低点）这个位置是有效的」；第一次追高若把止损老老实实放在分歧低点，「一点事没有」。最后靠假突破收回再起来把仓位接回来，他自评纯属**狗运（41:33）**——「再走十次，可能有六次就丢掉了」，很多票直接收敛起来，根本不给接回的机会。
- 阶段定级：从启动点数，五浪已走完，接下来是**大分歧**（还不是超大分歧，因为上方还有空间）；要等走到关键点位（0.5/1 元这类整数位、5 倍/10 倍位）开始走不动，才是超大分歧。没仓位的参与机会只有一个：等分歧、企稳、做进去。

## 规则增量
1. **成本锚持仓法**：预判不了路径和高度时，用失效点管理持仓——跌穿成本/关键位 = 这波结束，出；不跌穿就拿。目标区（如 42k）到了就进入「到哪停在哪出」的兑现模式。
2. **行情质量 = 确定性，不是幅度**：一轮行情有逻辑的交易笔数有上限（USTC 案：4 笔 × 试错 3 次 = 12 笔），超出预算的都是无效交易；幅度再大的不确定行情也是垃圾行情。
3. **突破止损无效论**：小分歧/分歧结构里，止损只能放在分歧低点（结构失效位）；放在突破位等于没止损。追高配套动作必须真执行：说好放大止损就要放大，否则不追。
4. **止损坚守**：止损设在有效位置之后不许临场挪动、不许提前手动出——他 BIGTIME 的反复止损全是没坚守自己设的止损，与仓位重不重无关。
5. **聚焦核心**：只做最强的那一个龙头，接也只接大结构（「大盆景」）；什么都接必然一起往下掉；觉得龙头高了、没机会了，就耐心等调整，除此之外不要看别的。
6. **同位置不同命**：同一只票、同一个价格位置，第一轮主升里做和行情走完后在震荡区里做，是完全不同的两笔交易——先定级（第几波/什么阶段），再决定做不做。
