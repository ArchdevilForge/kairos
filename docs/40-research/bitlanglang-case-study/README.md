# BitLanglang case study — supplementary sources for Phase 3a

Vendored 2026-11-11 from `xeronsh/video-distill-pipeline` → `case-study/bit-langlang/`
(the owner's distillation repo; full set also in the local knowledge base + Drive backup).

Contents:
- `DELIVERY_AUDIT.md` — the 4,807-trade delivery-record audit (2022-05 → 2024-06):
  verdict + the five corrections to the strategy summary. Calibration facts for
  operationalization live here (trial-layer cost structure, holding-time bands,
  leverage-discipline windows).
- `episodes/` — 24 per-episode distilled notes: the worked examples behind the
  summary's rules (e.g. EP02 ARK as the point-1→2→4 template, EP10 TRB box-breakout
  order template, EP19 divergence handling). Mine these when a summary rule is too
  coarse to operationalize.
- `delivery/audit_stats.json` — computed audit statistics.
- `SOURCE_MAP.md` — episode ↔ source-video mapping.

Not vendored (too large / not needed for operationalization): keyframe screenshots
(`frames/`, 95 images) and the raw delivery exports (`bitlang_trades_*.xlsx`,
`trades_clean.csv`) — both in the source repo above.
